# Replay Take 79
Exploratory, not a Gate or a candidate. Unpack into a clean directory on Linux with Python 3.10.12, NumPy 2.2.6, SciPy 1.15.3. Run `sh reproduce79.sh`, then `sha256sum -c SHA256SUMS`. BLAS/locale/thread controls are set by the script. Numeric text representations may differ with other library versions.

`reference74.json` is the unmodified PR #24 geometry at f54d9fefa427ee0fb30e601d4bd8b16f20d08b11. `catalog-reserves79.json` carries only the listed yaw, foot, and electronics stock; transforms in installed79.py and drive79.py place it in this study. No Take 75 ring or disk is a dependency. `stocklib79.py` is the finite support/inscribed-material helper. `key79.py` establishes datums/guide engagement; `installed79.py`, `drive79.py`, `hold79.py`, `latch79.py`, and `package79.py` build successive geometry groups. The frozen installed configuration is ONLY the combination in package79.py, not each intermediate constructor independently. hold79.py also records the abandoned pivot-hook interference. sweep79.py provides pair tests; finish79.py provides the machined cover stock, not the final envelope optimizer.

Read the named text outputs for dimensions, units, and limitations. The coverage optimizer and inspection cutaway are separate: outer stock never proves a material collision. `cutaway79.scad` is generated; set section=false, cover=true and optionally mating_tail=true to inspect externally. key_open/input_y/latch_angle are independent inspection controls, not commands or physical constraints. The ram is a reservation; thread and involute bodies are stock envelopes, not export-ready gears. SCAD is not required for replay; no rendered mesh is considered contact evidence.
