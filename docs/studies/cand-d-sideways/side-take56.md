# Take 56 — finite C-channel with positive side discharge
**Exploratory. Reject this installation; no loaded-release or Ø60 acceptance.** The passive flange of a short-neck ball is not another driven mechanism. One slide draws that ball into Take 54’s finite six-flat registry; a second screw on that slide drives a full-section, stepped plug. No lace, equalizer, twin receiver, stud-feed motor or chain store. A shorter plug is enough to occlude the cavity but *not* enough to prevent a loaded shoulder jam. No changes to Q12, Q38, Q85, Q100, criteria, candidates or official results.

## Reproduce
From this directory, with Python 3, NumPy and SciPy:

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONHASHSEED=0
python3 -B side-install-take56.py search
for i in install audit roll witness; do python3 -B side-$i-take56.py; done
```

JSON groups use hull(vertices) plus sphere/disk pad, disk axis in world coordinates. Circular channel is authoritative; outer wedge hulls conservatively enclose material for clearances, inner ones certify material. Positive support gaps certify; negative support gaps alone do not. Common-ball LP uses inscribed material, not hollow OD blanks. Script outputs preserve full precision. No physics solver result, physical test, Gate run or selection.
