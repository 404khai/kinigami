# Mechanical plug transfer — exploratory

Can a positively retracted male plug replace the seal-dependent handoff? **Not in either section as drawn.** A smooth working crown is promising in the seated state. A different contact carries the load when the shoe withdraws. Neither diameter-only packaging nor the crown's seated pressure establishes release.

| Check | Reproducible result | Limit |
| --- | --- | --- |
| [Take 22, one keyed button](button.md) | A finite collar shields its port lip; 55 N actual draw and ≤16 N net side force bound the heaviest seated crown at 117.64 N. | During withdrawal the rounded transition screens at 5.65 GPa even in the proposed free-guide case. No installed guide or full backing transfer has that force bound. |
| [Take 23, separate six-lobe section](plug-drive-take23.md) | A p5-backed lock land overlaps the nose by 0.271 mm before draw. The blind floor occupies the same volume as the motor. Moving it aft enough gives a 66.17 mm two-feature lower bound. | Only this arrangement fails; the six-lobe receiver is not Take 22's continuous torus. |
| [Crown against flat](crown.py) | At R13.5 and 57.5°, the wider 70 g load box needs 48.98 N actual axial draw for the table case. [Verified dual bounds](supported.py) give ≤62.89 N on any outer V flank over 50–55 N draw, without equal sharing. | Only while the six defined normals are available. A positive frictionless solution is not a lower bound on each actual frictional load. The proposed source, geometry and mass still need to deliver this draw. |
| [Rounded ejector coverage](ejector.py) | For p5-backed stock inside the stated projection, a central R3 cap, six at R11 and a hoop at R19 give ≥0.376 N axial per N after dry friction and errors. | The central rod crosses the draw contact and the R11 rods cut 1.76 mm into the nose. The proof also excludes entry behind the rods and uncontrolled exterior contacts; no release credit. |

The six-V dual checks bound circumferential and transverse force at each allowed contact using circumscribed Coulomb polygons, perturbing the normal, the centre and the contact location. Each computed dual is tested against every vertex, including the tolerance debit. The position in the force/moment matrix is the sphere-centre triangle at x28.492, **not** the x25.806 thrust contact; the 2.686 mm axial arm is debited. The Hertz check takes 213 GPa and ν=.29 from [ASSAB Caldie, p.4](https://www.assab.com/app/uploads/sites/199/productdb/api/caldie-en.pdf). Its representative 2350 MPa compressive proof stress at 60 HRC is not an allowable peak Hertz pressure. [Recanati, table 2](https://www.aimnet.it/la_metallurgia_italiana/2022/ottobre/Recanati.pdf) lists 0.1–0.2 against steel for the cited dry DLC coatings; neither that table nor this screen certifies an installed worst-case μ=.23. The scripts vary that input rather than treating it as an acquired component rating.

Run each Python script in this directory with `python3 -B` (NumPy/SciPy for the matrix/LP checks). The studies do not modify a declaration, establish whole-machine infeasibility, or supply independent reviews.
