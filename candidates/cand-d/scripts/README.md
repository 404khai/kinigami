# cand-d declaration and paper checks

Plain Python 3, no third-party packages. Run them from this directory, except `gen_declaration.py`, which runs anywhere.

| Script | What it does |
| --- | --- |
| `declaration_text.py` | Writes `declaration_text.json`: the prose fields (summary, retention, alignment, limitations, assembly). Every number in it is printed by `coupler.py` or `joint.py` |
| `gen_declaration.py` | Builds `../declaration.json` from the parameters and `declaration_text.json` (`--write`). Without `--write` it prints its own checks: oriented-box overlap with the protocol's 1 µm erosion (separating-axis test), containment in a cavity primitive, mass sum, centre of mass, peak power |
| `coupler.py` | Cam stages and first contact; pilot and lug guidance; series-elastic close, passive hold and independently driven reverse; load, friction and tolerance cases. Not a physical qualification test |
| `rear_drive.py` | Blind housing floor, cross-riveted collar and sleeve fits, end play, worst-side thrust reaction, reverse dog stress and cartridge material volumes |
| `joint.py` | Joint range from segment outlines, conservative full-sector swept-volume check against declared hardware, joint torque and current declaration weight |
