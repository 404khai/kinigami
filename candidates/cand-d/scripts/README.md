# cand-d reproducibility

Current: [v7 six-coordinate shutter](../dossier-v7.md). Use Python 3; the reciprocal wrench calculation additionally uses NumPy (tested with 2.2.6). No Python dependency is used by the Zig evaluator or simulation core.

1. Run `declaration_text.py` then `gen_declaration.py`; add `--write` to the latter to regenerate the declaration. No network inputs.
2. Run `rear_drive.py` (stock and section), `shutter_section.py` (slot separation, drive and ejection), `reciprocal.py` (full six-contact 3D wrench and subsets).
3. Run `coupler.py` (actual mass, Hertz and backlash) and `joint.py` (joint sweep and drive). Only the pinned evaluator is authoritative for Gate 1.
